어드민에서 저장하면 자동으로 빌드됩니다

보통은 저장만 해도 자동 배포됩니다.
빌드가 안 됐거나 수동으로 재빌드하고 싶을 때만 아래를 사용하세요.

🔄 수동 재빌드 방법
  • 아래 버튼을 눌러 Netlify 배포 페이지로 이동
    Netlify 배포 페이지 열기 →
  • Trigger deploy 버튼(또는 드롭다운) 클릭
    → "Deploy site" 선택
  • 빌드 상태가 Published 로 바뀌면 완료 (약 2~3분)
빌드 중에는 Building 상태. 완료 전에는 사이트에 반영 안 됨.
색인이 변경되었을 때 해야 할 일
작업 사례 추가, generateCount 변경, 새 페이지 생성 후에는 검색엔진에 사이트맵을 다시 알려줘야 빠르게 반영됩니다.
G 구글 서치콘솔 — 사이트맵 재제출
  • 아래 버튼 클릭 (구글 계정 로그인 필요)
    구글 서치콘솔 사이트맵 열기 →
  • 사이트맵 URL 입력창에 입력 후 제출
    https://your-domain.kr/sitemap.xml
  • 상태가 성공으로 바뀌면 완료
N 네이버 서치어드바이저 — 3단계 작업
  • 아래 버튼 클릭 (네이버 계정 로그인 필요)
    네이버 사이트맵 제출 열기 →
  • 사이트맵 입력창에 입력 후 제출
    https://your-domain.kr/sitemap.xml
  • 웹페이지 수집 요청: 핵심 URL 개별 추가 수집 요청
    요청 → 웹페이지 수집 → URL 입력 → 확인
    ※ 하루 할당량이 있으니 중요한 URL 위주로
    네이버 서치어드바이저 →
네이버는 자동 재크롤이 느립니다. 키워드나 사례를 추가한 날 직접 제출해두는 게 좋습니다.

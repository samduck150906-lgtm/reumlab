# 4. 변경 파일과 변경 이유

## 소스 변경: 1개 파일

| 파일 | 변경 | 이유 |
|---|---|---|
| `styles.css` | 맨 끝에 `HOME REDESIGN` 블록 추가 (+273줄) | 홈 전용 시각 레이어. 모든 선택자가 `body[data-page-type="home"]` 아래. |

**변경하지 않은 파일**: `index.html`, `script.js`, `app/**`, `content/**`, `public/**`,
`scripts/**`, `netlify.toml`, `package.json`, `package-lock.json`.

`index.html` 을 건드리지 않았기 때문에 문구·헤딩·링크·메타·JSON-LD·로고 마크업·폼 필드·
계측 훅(`data-cta` 등)은 **검사 이전에 구성으로** 보존됩니다.

## 빌드 산출물에 실제로 반영된 차이: **`out/styles.css` 1개**

Next 정적 export 는 빌드마다 build ID 가 바뀌고 그 값이 모든 페이지에 박혀 있어서
**같은 소스로 두 번 빌드해도 2,708개 파일이 "다름"으로 나옵니다.** 그래서 대조군을 만들었습니다.

| 비교 | 실제 내용이 달라진 파일 |
|---|---|
| 대조군: 같은 소스 2회 빌드 | 20개 (모두 287바이트짜리 Next 청크 stub — build ID 때문) |
| 변경본: 리디자인 적용 | 21개 = **위 20개 + `styles.css`** |

즉 **HTML 1,349개가 전부 바이트 단위로 동일**합니다.
(도구: `tools/home-redesign/artifact-diff.mjs`, 결과: `evidence/artifact-diff-{control,after}.json`)

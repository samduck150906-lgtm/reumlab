# Fact gaps

확인할 수 없어 새 주장으로 추가하지 않았거나 구조화 데이터에서 제외한 항목이다.

| 항목 | 현재 처리 | 필요한 증빙/결정 |
|---|---|---|
| 법적 상호(`legalName`) | 빈 값, schema 미출력 | 사업자등록증의 정확한 상호 |
| 성아름 대표자의 founder 여부 | founder 미출력 | 공개 가능한 창업자 사실 확인 |
| 외부 프로필 소유권·최신성 | 기존 URL만 유지 | 각 계정 소유자 로그인 확인 |
| 우편번호 18469 최신성 | 기존 코드 값 유지 | 도로명주소 공식 조회 |
| 실제 방문 상담 가능 여부·영업시간 | 지점 확장/LocalBusiness 미추가 | 방문 정책과 공개 영업시간 |
| 총 프로젝트 수·팀 규모·업력 | 주장하지 않음 | 공개 가능한 증빙 |
| 고객별 성과·전환·비용 절감 | 수치 추가하지 않음 | 익명 공개 동의와 측정 자료 |
| 고객 후기·평점 | Review schema 미사용 | 출처·동의·원문 확인 |
| 엔터프라이즈 RAG/에이전트 실제 납품 범위 | 기존 페이지의 한계 공개 유지 | 계약상 공개 가능한 사례와 담당 범위 |
| 보안 인증·수상·파트너 | 주장하지 않음 | 공식 인증서/발표 페이지 |
| 계약서·하자·유지보수 표준 조건 | 기존 공개 범위만 유지 | 법률 검토된 공개본 |
| 모든 AI 검색 유입의 식별 | 불가능하다고 명시 | 리퍼러/플랫폼 보고서 제공 여부 |

이 항목이 확인되기 전에는 코드, schema, FAQ, 사례에 확정 사실처럼 넣지 않는다.

## 고객 사례 공개 동의 요청 초안

> 안녕하세요. 름랩 홈페이지에 해당 프로젝트의 문제, 름랩이 맡은 범위, 구현 기능, 기술, 인도한 산출물을 사례로 소개해도 될지 확인 부탁드립니다. 상호·로고·서비스 URL·화면 중 공개할 수 있는 항목을 각각 선택해 주세요. 승인하지 않은 항목은 기존처럼 익명처리하겠습니다. 성과 수치는 확인 가능한 자료가 있고 별도로 승인하실 때만 사용하겠습니다.

## 솔직한 후기 요청 초안

> 프로젝트 진행에서 도움된 점과 아쉬운 점을 솔직하게 남겨 주시면 서비스 개선에 활용하겠습니다. 긍정적 표현을 요청하거나 공개를 강제하지 않습니다. 홈페이지 공개 여부와 실명·익명 범위는 따로 확인하겠습니다.

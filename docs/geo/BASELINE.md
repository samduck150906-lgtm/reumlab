# REUMLAB GEO baseline

기준일: 2026-09-10 (Asia/Seoul)

## 범위와 방법

- 저장소, 정적 빌드 산출물 `out/`, 공개 사이트의 대표 페이지와 공식 검색 문서를 조사했다.
- URL 상태는 Netlify `_redirects`와 정적 산출물을 결합한 배포 모델로 판정했다. 실제 프로덕션 동작은 배포 후 다시 확인해야 한다.
- 콘텐츠 평가는 단어 수만으로 통과시키지 않았다. 직접 답변, 검증 가능한 사실, 고유한 판단 정보, 한계 공개, 내부 링크, 구조화 데이터를 별도 열로 기록했다.
- 고객사·성과·경력·지점·인증을 새로 추정하지 않았다.

## 기술 구조

- Next.js 14.2 정적 export와 별도 정적 홈(`index.html`)을 함께 빌드한다.
- 콘텐츠 원본은 `lib/`, `content/`, 생성 스크립트에 분산되어 있으며 포트폴리오·랜딩·클러스터 JSON은 빌드 전 재생성된다.
- Netlify Forms, GTM/GA4 dataLayer, Meta Pixel 연동이 존재한다.
- `app/robots.ts`, `app/sitemap.ts`, `scripts/generate-feed.mts`, `scripts/submit-indexnow.mjs`가 각각 robots, sitemap, RSS, IndexNow를 담당한다.

## 확인된 강점

- 홈에 VAT 포함 패키지 가격·기간, 진행 순서, 소스코드와 운영 권한 이관 원칙이 초기 HTML로 공개된다.
- 15개 익명 사례의 문제·기능·범위·기술·산출물이 초기 HTML에 있으며, 가짜 평점이나 성과 수치를 사용하지 않는다.
- 45개 가이드에 핵심 요약과 본문 앵커가 있고, Article 계열 구조화 데이터와 화면 내용이 연결된다.
- canonical, sitemap, robots, 내부 링크, JSON-LD를 검사하는 기존 QA가 폭넓게 갖춰져 있었다.

## 확인된 우선 위험

1. 성남 지역의 구형 `/l/` URL과 현행 지역 서비스 URL이 같은 의도를 나눠 가졌다.
2. 과거 생성 설정에 `인계동`이 대표 지역처럼 남아 현재 동탄 사업장 신호와 충돌할 여지가 있었다.
3. `legalName`과 `founder`가 공개 근거 없이 구조화 데이터에 들어가 있었다.
4. 서비스 히어로에 검색 키워드 배열이 칩 형태로 그대로 노출됐다.
5. Windows에서 빌드·감사 경로 정규화가 되지 않아 QA가 대량의 거짓 오류를 냈다.
6. 777개 색인 URL 중 업종·비용·솔루션·웹사이트 템플릿 축이 크다. 정확 중복은 없지만 실제 근거 밀도는 계속 수동 점검해야 한다.
7. 색인 URL 109개가 홈에서 6클릭 이상이며 최대 깊이는 12다.

### Enterprise AI Definition

> 사내 AI는 기업이 보유한 문서와 업무 데이터를 활용해 임직원의 질문에 답하거나 필요한 정보를 찾도록 돕는 내부 업무지원 AI입니다.

### RAG Explanation

> RAG(Retrieval-Augmented Generation)는 AI가 질문을 받았을 때 관련 사내 자료를 먼저 찾아보고, 검색된 내용을 참고해 답변하도록 만드는 방식입니다.

흐름: ① 사용자 질문 → ② 관련 자료 검색 → ③ 필요한 내용 추출 → ④ 언어모델에 전달 → ⑤ 답변 생성.

**한계를 같은 섹션에 명시했다** — 잘못된 답을 없애는 기술이 아님 / 검색 품질이 상한을 정함 /
문서가 최신이 아니면 답도 최신이 아님 / 스캔 PDF·표 문서는 추출 품질에 좌우됨.

### Security Content

마케팅 문구가 아니라 **도입 전에 회사가 정해야 할 항목**으로 구성했다.

- **권한**: 화면에서 가리는 방식이 아니라 검색 단계에서 조회 대상을 나눈다. 단, "이것으로 모든 보안 요구가 해결된다"고 쓰지 않음.
- **데이터**: 검색 대상에 넣을 자료 / 제외할 자료를 목록으로 먼저 확정 — 그 범위가 곧 시스템의 조회 한계.
- **외부 모델/API**: 상용 API 를 쓰면 질문과 검색된 문서 일부가 전송된다는 사실을 그대로 적고, 민감 항목 제외·마스킹을 설계 항목으로 둠.
- **로그**: 질문·답변 기록이 그 자체로 민감 정보가 될 수 있음 → 보관 범위·기간을 정함.
- **배포환경**: "기존 인프라와 보안 요구사항을 확인한 뒤 적합한 구성을 설계합니다."
  **온프레미스·폐쇄망 구축은 검증되지 않아 한 번도 주장하지 않았다.**

### Enterprise AI vs Automation

**사내 AI**는 회사 자료에서 정보를 찾아 답하는 서비스다(예: "휴가 규정 알려줘" → 사내 규정 검색 → 근거와 함께 답변).
**AI 업무 자동화**는 반복되는 업무 흐름을 시스템이 대신 실행하는 서비스다(예: 승인된 신청서를 담당자에게 자동 전달).
두 서비스는 경쟁이 아니라 결합 가능하며, 직원이 사내 AI 로 정보를 찾고 그 자리에서 요청을 실행하는 흐름으로 이을 수 있다.
다만 **중요한 업무를 사람 확인 없이 AI 가 실행하는 구성은 권하지 않는다**고 페이지에 명시했다.
단순 RAG 챗봇을 "AI Agent" 로 포장하지 않았다.

## Final Verdict

**1. "사내 AI 구축" 검색자가 원하는 정보를 충분히 얻는가?**
얻는다. 무엇인지(정의) · 일반 AI와 뭐가 다른지(비교표) · 우리 자료로 되는지(데이터 유형) ·
권한을 나눌 수 있는지 · 보안에서 뭘 정해야 하는지 · 어떻게 만드는지(6단계) · 얼마인지(결정 요소 11 + 공개 패키지) ·
작게 시작할 수 있는지(PoC)까지 한 페이지에서 답한다. 판단이 더 필요하면 가이드 3편으로 이어진다.

**2. 기존 "AI 자동화" 페이지와 검색 의도가 명확히 다른가?**
다르다. 실행(automation) vs 검색·질의응답(retrieval)으로 나뉘고, 본문 유사도 0.16(임계 0.72)이다.
두 페이지가 서로를 문맥 링크로 가리키며 "무엇을 찾는 사람은 어디로" 가야 하는지 명시한다.

**3. 기술 담당자가 아닌 기업 의사결정자도 이해할 수 있는가?**
히어로에 RAG·Vector DB·Embedding·LLM 을 넣지 않았다. 첫 화면은 "우리 회사 자료로 답하는 AI"라는
가치 한 줄이고, 기술은 전용 섹션에서 비유 없이 단계별로 설명한다.

**4. RAG/보안/연동을 과장 없이 설명하는가?**
RAG 섹션에 「RAG로 해결되지 않는 것」을 같은 깊이로 넣었고, 보안은 약속이 아니라 결정 항목 6가지로 썼다.
연동은 "규격이 공개돼 있으면"이라는 조건을 매번 붙였다. 온프레미스·폐쇄망은 검증되지 않아 언급하지 않았다.
금지 표현 자동 검사 0건.

**5. 상담으로 이어지는 자연스러운 전환 경로가 있는가?**
정보 검색 → 가이드 → 상업 페이지 → 문의 경로가 양방향으로 배선돼 있고, CTA 는 위치별로 다르다
(가능 여부 확인 → 자료 기준 범위 확인 → 상담). 문의 폼에는 유입 경로·페이지 유형이 함께 저장되어
어느 축이 계약을 만드는지 나중에 확인할 수 있다.

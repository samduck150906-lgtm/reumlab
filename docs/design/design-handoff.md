## 7. 기능 / 기술 명세 (디자인이 깨면 안 되는 동작)

- **호스팅**: Next.js 14 App Router, **정적 export(`out/`)** → Netlify. 서버 없음(모든 폼은 클라이언트/외부 서비스).
- **상담폼**: Web3Forms(`NEXT_PUBLIC_WEB3FORMS_KEY`). 미설정 시 mailto 폴백. 허니팟 스팸 차단.
- **분석**: GTM(`NEXT_PUBLIC_GTM_ID`) + 선택 Meta Pixel. 클릭은 `data-analytics`, 폼 전환은 `generate_lead`.
- **카카오 채널**: `NEXT_PUBLIC_KAKAO_CHANNEL_URL` 설정 시 플로팅에 노출.
- **SEO**: 페이지별 메타/OG/JSON-LD(Organization·Breadcrumb·Article·CreativeWork) 적용 중 → 마크업 변경 시 메타 구조 유지.
- **반응형 필수**: 모바일 터치 타깃 최소 44px(`--touch-min`). iOS safe-area 변수 사용 중.
- **폰트**: 현재 Google Fonts 4종 동기 로드(렌더 블로킹) → 성능 위해 `next/font` 전환 권장(디자이너 인지용).

   - *추천: A안(네이비/블루) — 외주 의사결정자에게 신뢰감, 메인이 이미 최신*

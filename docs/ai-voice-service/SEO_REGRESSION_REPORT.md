## 3. 의도한 사이트 공통 변경 1건

공유 컴포넌트 `components/LandingInquiryForm.tsx` 를 쓰는 **204개 페이지**의 폼 안에
비-JS 대안 안내를 추가했다(페이지당 +103자).

```
자바스크립트가 꺼져 있어 전송 결과를 화면에서 확인해 드릴 수 없습니다.
아래로 바로 연락 주셔도 됩니다 — 전화 010-8111-9370 · 이메일 ceo@eternalsix.com
```

**왜 공통으로 넣었나**
명세 §10.4 는 "noscript 에서는 native 제출이 실제 처리되는지 검증. 불가능하면 이유를
알리고 검증된 전화·이메일 경로 제공. **무반응 폼 금지**"를 요구한다.
이 환경에서는 native 제출의 실제 처리를 확인할 수 없다(§LEAD_DELIVERY_CHECK).
그런데 이 폼은 ai-voice 전용이 아니라 공유 컴포넌트다. ai-voice 에만 대안을 넣으면
나머지 변형은 여전히 "JS 없으면 아무 반응 없는 폼"으로 남는다.
→ **필드를 추가하지 않고 안내만** 전 변형에 넣었다.

**영향 범위 확인**
- 필드 추가·삭제·이름 변경 **0건** (접수 데이터 구조 불변)
- `/geo-website/` 27필드 · `/ai-search-optimization/` 31필드 — 브라우저로 확인, 변화 없음
- 두 페이지 모두 console 오류 0, 제출 버튼 문구 유지
- `tel:` 링크 수가 205개 페이지에서 증가한 것은 이 블록 안의 전화 링크 때문이다

**되돌리는 법**: `components/LandingInquiryForm.tsx` 의 `<noscript>` 블록 하나만 지우면 된다.

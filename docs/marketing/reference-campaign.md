# 름랩(Reum Lab) 레퍼런스 확보 캠페인

> 목적: 초기 3~5건의 프로젝트를 **마진을 낮춰** 수주하는 대신, 신뢰 자산(실명 후기·스크린샷 사용권·사례 인터뷰)을 **계약서에 명시해** 확보한다.
> 핵심 원칙: 솔직하게, 과장 없이. "레퍼런스가 없다"는 약점을 숨기지 않고, 오히려 제안의 출발점으로 쓴다.

## 1. 레퍼런스 확보 계약 구조

### 1-1. 제안 흐름

1. **솔직하게 시작한다.** "름랩은 이제 막 외부 사례를 쌓는 단계입니다. 그래서 초기 N팀에 한해 레퍼런스 조건으로 가격을 낮춰 진행합니다."
2. **대가를 명확히 한다.** 낮춘 가격은 '공짜'가 아니라 **후기·스크린샷·인터뷰와의 교환**임을 분명히 한다.
3. **고객 부담을 줄인다.** 후기 작성은 5문항 설문으로, 인터뷰는 30분 이내로 제한해 "시간 많이 안 든다"는 점을 강조한다.
4. **거부권을 보장한다.** 민감 정보는 비공개 처리, 공개 전 최종 검수권을 준다. 이게 있어야 실명 동의가 쉽게 나온다.

### 1-2. 계약서 삽입 조항 예시 문구

> 아래 문구는 표준 용역계약서에 **추가하는 특약 형태**로 삽입합니다. 실제 사용 전 변호사 또는 법률 검토를 한 번 받는 것을 권장합니다.

**제O조 (레퍼런스 협조 및 콘텐츠 사용권)**

```
① "갑"(고객)은 본 용역이 레퍼런스 확보 목적의 할인 조건으로 체결되었음을 확인한다.
   이에 따라 "갑"은 아래 각 호의 협조를 제공한다.

   1. 프로젝트 종료 후 14일 이내, "을"(름랩)이 제공하는 설문(5문항)에 대한
      서면 후기 작성
   2. 후기에 상호 또는 실명, 직함의 표기 동의
   3. 30분 이내의 사례 인터뷰 1회 참여(서면·통화·화상 중 택1)

② "갑"은 본 용역으로 제작된 결과물의 화면(스크린샷), 후기 전문 및 발췌,
   인터뷰 내용을 "을"이 아래 용도로 사용하는 것에 동의한다.

   - 름랩 공식 웹사이트, 포트폴리오, 제안서
   - 크몽 등 외부 마켓플레이스 상세페이지
   - 름랩 운영 SNS 및 마케팅 채널

③ 공개 보호 장치
   1. "갑"이 사전에 '비공개'로 지정한 정보(매출, 개인정보, 미공개 사업 내용 등)는
      사용 대상에서 제외한다.
   2. "을"은 후기·스크린샷·인터뷰를 외부에 처음 공개하기 전 "갑"에게
      최종본을 공유하고, "갑"은 영업일 기준 5일 이내 수정·삭제를 요청할 수 있다.
   3. "갑"은 본 조항에 따른 사용 동의를 서면 통지로 언제든 철회할 수 있으며,
      "을"은 통지 수령 후 합리적 기간 내에 신규 게시를 중단한다.
      (이미 인쇄·배포된 자료는 회수 대상에서 제외)

④ 본 조항에 따른 협조는 제1항의 할인 조건에 대한 대가이며, 별도의 추가
   보수는 발생하지 않는다.
```

**소스코드 이관 관련 기존 조항(참고용 재확인)**

```
⑤ "을"은 본 용역 완료 및 잔금 지급 후, 결과물의 전체 소스코드 및 관련
   자료 일체를 "갑"에게 이관한다. "갑"은 이관받은 소스코드를 제한 없이
   수정·사용할 수 있다.
```

> 름랩의 핵심 차별점(소스코드 전체 이관, AI 도구로 직접 수정하는 법 1:1 교육, 가격 선공개)은 계약서에도 명시해 두면 "이 조건이 진짜구나"라는 신뢰로 이어집니다.

```

편하게 쓰시면 5분 정도면 충분합니다. 솔직한 내용일수록 좋습니다.
(아쉬웠던 점도 그대로 적어주세요. 다음 분들께 더 잘하기 위해서입니다.)

작성해 주신 후기는 공개 전에 최종본을 먼저 보여드리고,

```

### 3-2. 후기 설문 5문항

```
1. 름랩에 의뢰하기 전, 가장 큰 고민이나 막혔던 점은 무엇이었나요?

2. 여러 선택지 중 름랩을 고른 결정적인 이유는 무엇이었나요?

3. 작업 과정에서 가장 만족스러웠던 점, 그리고 아쉬웠던 점은 무엇인가요?

4. 결과물(또는 소스코드 이관·1:1 수정 교육)이 실제 사업에 어떤 도움이 되었나요?
   (가능하면 구체적인 변화나 경험을 적어주세요)

5. 비슷한 고민을 하는 다른 창업가에게 름랩을 추천한다면, 한 줄로 어떻게 말하시겠어요?
```

## 4. 받은 후기 재활용 배치 가이드

> 같은 후기 하나를 채널별 형식에 맞게 변형해 여러 곳에 배치합니다. **없는 후기를 만들지 말 것** — 받은 내용 그대로, 발췌·요약만 합니다.

### 4-1. 름랩 웹사이트

- **위치**: 메인 페이지 하단 + 별도 '고객 사례' 페이지
- **형식**:
  - 한 줄 인용(설문 5번 답변) → 카드 형태로 메인에 노출
  - 전체 사례는 "고민 → 선택 이유 → 결과"의 흐름(설문 1·2·4번 활용)으로 구성
  - 결과물 스크린샷 1~2장 + 표기 동의 범위에 맞춘 이름/상호
- **체크**: 비공개 동의 정보가 섞이지 않았는지 게시 전 확인

### 4-2. 크몽 (및 외부 마켓플레이스)

- **위치**: 서비스 상세페이지 중상단
- **형식**:
  - 신뢰가 급한 채널이므로 후기 발췌를 **눈에 띄는 인용 블록**으로 배치
  - 설문 3번(만족점) + 4번(사업 도움)을 묶어 "이런 결과를 만들었습니다" 톤으로
  - 가격 선공개·소스코드 이관 같은 차별점과 후기를 나란히 배치해 설득력 강화
- **체크**: 마켓플레이스 정책상 외부 연락처·실명 노출 제한 여부 확인

### 4-3. SNS

- **위치**: 정기 게시 (예: 사례 1건당 카드뉴스 1세트)
- **형식**:
  - 1번 슬라이드: 고객의 고민 한 줄(설문 1번)
  - 2~3번 슬라이드: 결과·변화(설문 4번) + 스크린샷
  - 마지막 슬라이드: 추천 한 줄(설문 5번) + 름랩 소개/문의 안내
  - 짧은 인용은 텍스트 단독 포스트로도 재활용
- **체크**: 인용 동의가 'SNS 사용'까지 포함됐는지 확인 후 게시

### 4-4. 재활용 우선순위 (1건 후기 → 배치 순서)

| 순서 | 채널 | 활용 형태 |
| --- | --- | --- |
| 1 | 웹사이트 고객 사례 | 전체 사례(고민→선택→결과) |
| 2 | 크몽 상세페이지 | 발췌 인용 블록 |
| 3 | 웹사이트 메인 | 한 줄 인용 카드 |
| 4 | SNS | 카드뉴스 + 단독 인용 포스트 |

## 5. 실행 체크리스트

### 준비 단계
- [ ] 레퍼런스 한정 건수(N)와 할인 내용 확정
- [ ] 계약서에 레퍼런스 협조·콘텐츠 사용권 특약 삽입 (가능하면 법률 검토 1회)
- [ ] 후기 설문 5문항 + 인용 동의서 양식 파일로 준비
